# Human Body Explorer — Responsive Offline Science Exhibition

## Run
1. Extract `Human-Body-Explorer.zip`.
2. Keep the `images` folder in the same place as `index.html`.
3. Double-click `index.html` and open it in Chrome.
4. Select a body system from the left drawer. On a phone, swipe the top navigation bar sideways to see all systems.
5. Switch between English and Kannada using the top-right button.

## Features
- Responsive desktop, tablet and phone layout
- Horizontal top navigation bar listing the whole body and nine body systems (scrollable on smaller screens)
- Click a system to display its detailed user-provided infographic and bilingual explanations
- Whole-body overview
- Science quiz
- Offline local images; no external URLs or server needed

## Main files
- `index.html`: page layout
- `style.css`: design and responsive phone layout
- `script.js`: system information, navigation, language switch and quiz
- `images/`: detailed anatomy posters supplied for this project
