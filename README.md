# 🧍 Human Body Explorer

Human Body Explorer is an interactive educational website that helps students learn about the human body in a simple and fun way.

## ✨ Features
- 🫀 Explore different human body systems.
- 🖼️ Learn using anatomy images and illustrations.
- 🌐 Available in English and Kannada.
- 📚 Simple explanations of organs and their functions.
- 🧠 Practice questions to test your knowledge.
- 📱 Responsive design for computers and mobile phones.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the human body systems!

## 🎯 Project Purpose
This project was created as a school science exhibition project to make learning human anatomy easy, interactive, and enjoyable.

## 👨‍🎓 Created For
A school science exhibition.
